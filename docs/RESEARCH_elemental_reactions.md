# RESEARCH: Elemental reaction → constituent elements

**Status:** research only. Nothing in this file has been lifted into code yet.

## What this is and how it was gathered

A table of every elemental reaction in Genshin Impact and the set of elements that must be
present for it to be possible, for a UI filter that classifies a user's teams by which
reactions they can enable.

**Retrieved:** 2026-08-29.

**Primary source — the Genshin Impact Wiki (Fandom), read as raw wikitext through the
MediaWiki API.** The owner supplied `https://genshin-impact.fandom.com/wiki/Elemental_Reaction`.
`WebFetch` on every `/wiki/` URL on that host returned **HTTP 402 Payment Required** (it is not
a Cloudflare challenge; `WebFetch` works fine on other hosts, e.g. `gcsim.app`). Plain `curl`
against the article HTML is the challenge case the owner described. What *does* work is the
wiki's own API, which `curl` reaches with HTTP 200 and which returns the page's **wikitext
source** rather than rendered HTML:

```
curl "https://genshin-impact.fandom.com/api.php?action=parse&page=<PAGE>&prop=wikitext&format=json"
```

**A note on how the per-reaction sentences were obtained.** Each reaction page's opening
sentence is generated by `{{Elemental Reaction Intro|element1=…|element2=…}}`. The wikitext of a
reaction page therefore gives the *arguments*, and `Template:Elemental Reaction Intro` gives the
*sentence*. Both were read. Quotes below are the template's sentence with its parameters
substituted, marked as such; where a page states something in its own prose (Bloom's
Hyperbloom/Burgeon paragraphs, Frozen's Shatter section, Catalyze's Quicken paragraph) the prose
is quoted directly.

**Secondary corroboration — gcsim, names only.** `pkg/core/info/reaction.go` at commit
`3647a07a7cc3004bc1e79d9bb5f7444de20dceaa` (fetched from `raw.githubusercontent.com`) was read
**only** to cross-check the reaction *name set* and the Swirl/Crystallize wildcard domain. No
element pairing in the table below is sourced from gcsim. Its `ReactionType` enum lists
`crystallize-{electro,hydro,pyro,cryo}` and `swirl-{electro,hydro,pyro,cryo}`, which agrees with
the wiki's wildcard domain, and it has `lunarcharged`, `lunarbloom`, `lunarcrystallize` and
`stellar-conduct` but **no Stellar Swirl** at that commit.

possible at all — the thing a team filter needs. It is not the trigger order; order matters for
damage (Melt/Vaporize multipliers) but not for whether the team can produce the reaction.

**Hyperbloom is confirmed as three elements** — Dendro + Hydro (to make the Dendro Core) +
Electro (applied to it). Burgeon is the same shape with Pyro. The source never states this as a
three-element set in one sentence; it states it as Bloom's product plus a third application, and
the overview table nests Burgeon/Hyperbloom inside the Hydro×Dendro cell.

The overview table also lists cells that are **not** reactions and must not be inferred into
one: Dendro + Cryo, Dendro + Anemo, Dendro + Geo, and every Geo-as-aura cell are all `—`.

### Categories, as the source names them

- **Transformative Reactions** — "include Overloaded, Shattered, Electro-Charged, Superconduct,
  Swirl, Burning, Bloom, Hyperbloom, and Burgeon."
- **Amplifying Reactions** — "include Vaporize and Melt."
- **Additive Reactions** *(unofficial name)*, "or simply denoted as 'Catalyze Reactions' in
  Miliastra Wonderland" — "include Spread and Aggravate."
- **Lunar Reactions** — "include Lunar-Charged, Lunar-Bloom, and Lunar-Crystallize."
- **Stellar Glimmer Reactions** — "include Stellar-Conduct and Stellar Swirl."

Frozen, Crystallize and Quicken are in **none** of those five lists — they deal no damage of
their own, so the source has no damage category for them. The JSON below marks them
`"category": null` rather than guessing.

## Uncertain or contested

1. **Shatter is not a pure element pair, and a filter that treats it as one will be wrong.**
   The source says "hit by a **Blunt** or Geo attack". A Blunt Attack is Physical, not an
   element — claymores and some plunges qualify. So a team with Cryo + Hydro + a claymore user
   can Shatter with no Geo at all. Modelling Shatter as `{Cryo, Hydro, Geo}` would under-count
   teams; modelling it as `{Cryo, Hydro}` would over-count them. The JSON records
   `non_elemental_trigger: "blunt_attack"` alongside the optional Geo, and marks the row
   `uncertain: true` for the filter's purposes. **Decide this deliberately rather than in code.**

2. **Whether the Lunar and Stellar Glimmer reactions require a party talent to occur at all is
   genuinely ambiguous in this source.** For **Lunar-Bloom** it is explicit: "Lunar-Bloom
   replaces Bloom when a character with the corresponding Moonsign Benediction talent is in the
   party." For **Lunar-Charged**, **Lunar-Crystallize**, **Stellar-Conduct** and **Stellar
   Swirl** the wording is "After triggering a *X* reaction with a character with [Moonsign
   Benediction / a Stellar Linchpin] in the party, [effect] will be created" — which reads as
   gating the *effect*, not the reaction. For **Stellar Swirl** the source names no party talent
   at all; it says only that Stellar Glimmer Reaction damage is multiplied by a bonus from
   "Stellar Jubilee Passives", which is a damage source and not a stated gate, so that row's
   `party_gate` is `null` rather than a guess. The Lunar Reactions section adds that these reactions
   "can be dealt either directly by a character's talent … or through a separate instance of
   damage", which does not settle it either. Each of these rows carries `party_gate` with the
   named talent and `party_gate_certain` set to `true` only for Lunar-Bloom. **A team filter
   that ignores this will tell a user with Hydro + Electro and no Moonsign character that they
   can do Lunar-Charged.**

3. **Swirl's "or vice versa" is theoretical for players.** The wiki footnotes it: applying Anemo
   to an existing aura is the normal case, and an Anemo *aura* to react into exists only on the
   Anemo Hypostasis, "as players cannot apply a persistent Anemo status." Does not change the
   element set; does mean the reverse direction should not be offered as a strategy.

4. **Geo can never be the aura.** The overview table's source carries the maintainer comment
   "STOP CHANGING THE GEO COLUMN, IT IS INTENTIONALLY LEFT EMPTY AS GEO CANNOT BE THE FIRST
   ELEMENT", plus a note that "the persistent Geo status on certain enemies cannot be reacted
   with, and players cannot apply a persistent Geo status without using Planet Befall."
   Crystallize and Lunar-Crystallize are therefore directional in a way Vaporize is not.

5. **Stellar Swirl is the thinnest-sourced row.** Its page is marked `{{Stub}}`, and gcsim at
   `3647a07a` implements the other four new reactions but has no Stellar Swirl. Its element pair
   (Anemo + Cryo) is stated in two independent places on the wiki — the overview table cell and
   the template's `Stellar Swirl = {{Cryo}}.` branch — so the pair is well attested even though
   the surrounding detail is not.

6. **Aura follow-ups that consume one reaction to make another** are recorded on the pages and
   are worth knowing before writing the filter, though they add no new element sets: inflicting
   Pyro/Electro/Anemo on a Freeze Aura triggers Melt/Superconduct/Swirl; inflicting Pyro or Hydro
   on a Quicken Aura triggers Burning or Bloom.

7. **Not checked, and deliberately out of scope:** Genius Invokation TCG has its own reaction
   rules on a separate page, and this file does not cover them.
