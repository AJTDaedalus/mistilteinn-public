## Item 6 — Dire Prestige per Condensed claim: **60** (community claim x3, consistent; no official post-Luna text found)
- BWIKI `幽境危战` (https://wiki.biligame.com/ys/幽境危战, wikitext read, last revision 2026-08-27): "其中 原粹树脂20 / 浓缩树脂1、脆弱树脂1、须臾树脂1 和原石 分别对应1倍/3倍奖励，累计20/60「危战勋望」" (Original resin 20 = 1x; Condensed/Fragile/Transient 1 = 3x; accrues 20/60 Dire Prestige).
- Miyoushe guides by 暖阳 (post 75218977, 2026-05-08, "月之七"; post 76214271, 2026-06-24, "月之八"): "1200÷60=20个浓缩树脂" to reach 1,200 Prestige, and "60点原粹树脂=1个浓缩树脂=1个须臾树脂=1个脆弱树脂". Also: Original claim "消耗20或40原粹树脂" (20 = 1x, 40 = 2x).
- Sohu 6.4 plan (https://m.sohu.com/a/990158678_122598898, 2026-02-26): "消耗2个浓缩/须臾/脆弱树脂＝消耗120原粹树脂＝额外获得1个金色品质圣遗物" (2 Condensed = 120 resin = 1 extra gold), i.e. 60 each.
- wiki:`Stygian_Onslaught` (Fandom, last edit 2026-10-03) body: "20 is given for Original Resin and 60 for Condensed, Transient or Fragile Resin."
- **Conflict (quote both):** the same Fandom page's two in-game tutorial transcriptions still read "Consuming Original Resin, Condensed Resin, Fragile Resin (or Transient Resin) will award 20/40/60 'Dire Prestige' respectively", i.e. Condensed = 40. These strings are the pre-Luna-I wording (Condensed was a 2x item then); the page never updated them. Every source written after Luna I that does the arithmetic uses 60.
- Net: Prestige = 1 per resin spent at every claim size (20 -> 20, 40 -> 40, Condensed 60 -> 60). Confidence: community claim, 4 independent mentions + arithmetic; no post-Luna official string found.

## Item 2 — Dust Reshape mechanics (partial; checkpoint 2)
**Still unverified as to mechanism; here is everything found.**
- Official text only: "All Minor Affixes enhancements will be reallocated, and at least 2 enhancements will be allocated to the selected Minor Affixes" (prior doc §5.7). Luna V note (wiki:`Version/Luna_V`): "In the 'Artifacts' > 'Reshape' screen, a secondary confirmation prompt appears when selecting a reshaping result with fewer Minor Affix rolls." (so a result can have fewer rolls on the chosen lines, and the keep-better choice is real). Luna I note: a fix so "the number of Minor Affix rolls in the Sanctifying Elixir Definition pop-up ... is not being updated promptly based on the reshaped Artifact's Minor Affixes".
- **Initial values kept?** Official wording says "enhancements ... reallocated", i.e. only the enhancement rolls. Hupu post by 家有徐小宝 (https://m.hupu.com/bbs/633298558.html, 2025-06-19): "初始四词条洗完，会强化5次" and for a 3-line piece "会保留你随机出的第四词条，但后续强化只有4次，其中必出2次指定词条" (keeps the fourth line, then only 4 enhancements). No sample size; a personal single example. Icy Veins' guide (search snippet only, page itself returned 403): "the item does not change the sub-stats, but only the number of upgrades each sub-stat gets". Genshin Optimizer's `dustReshape` keeps `initialValue` (PR #3231, throws if `initialValue` undefined). All consistent, none measured.
- **Budget of a 3-line piece:** 8 draws kept (3 initial + 4th line + 4 upgrades), not 9 (Hupu above; BWIKI 启圣之尘 says a 4-guarantee on a 3-initial piece is "必然稳中4次", i.e. all 4 post-fill enhancements are forced onto the chosen lines, which only makes sense if there are exactly 4). Community claim, consistent with GO.
- **Floor vs resample: two Miyoushe analyses disagree, neither measured.**
  - Miyoushe article republished at https://news.17173.com/content/07082025/113902029.shtml (2025-07-08): assumes the floor. Quote: "我们先假定启圣之尘的保底效果不提升基础概率" and shortfall enhancements are "在最后加到所选的两条词条中". Its table: 2 valid lines, 3 initial: "仅命中两次的情况为69%，三次25%，四次6%"; 2 valid / 4 initial: "命中两次50%，三次31%，四次16%，五次3%". These equal the exact floor binomial (68.75/25/6.25 and 50/31.25/15.6/3.1), i.e. an assumption, "no simulation size, no observed pull data".
  - Miyoushe script simulation republished at https://news.17173.com/content/07012025/142101415.shtml (2025-07-01, "脚本模拟100万次", "不考虑成长值情况下", "仅供参考"): 2 valid / 3 initial: hits 2 = 56.22%, 3 = 37.55%, 4 = 6.23%; 2/4: 40.65 / 40.57 / 15.63 / 3.14 (hits 2/3/4/5); 3/3: 14.04 / 46.92 / 39.04. It does not state how it models the guarantee.
  - **Derived (mine):** the floor model (GO's) gives 68.75/25/6.25 for 2/3, vs the script's 56.2/37.6/6.2; and 50/31.25/15.6/3.1 for 2/4, vs 40.65/40.57/15.63/3.14. The script agrees with the floor in the top tail (hits >= 4) and moves ~12.5 points (2/3) and ~9.4 points (2/4) of mass from "exactly 2" to "exactly 3". A plain conditional resample (hits >= 2) gives 54.5/36.4/9.1 for 2/3, which matches neither. So the one simulation that contradicts GO's floor is not a resample either; its mechanism is unexplained. The 3-guarantee ("Advanced") rows in the script match the floor pattern exactly (74.94/25.06 = 12/16, 4/16 for 2/3), so the discrepancy is confined to the baseline 2-guarantee case.
  - Hupu comments (2025-06-19) dispute a "50%" claim: one says "并非50%。圣遗物复制器说是。" (an artifact-copier simulator says otherwise), another asks "确定不是1/32全中吗". No data.
- Looked and found nothing measured: Genshin Optimizer repo (PRs #3231, #3235, #3262, #3264; issues search "reshape/dust/elixir"), r/Genshin_Impact and KQM via web search (Reddit itself returns 403/blocked to scripts; search returned no data post), AnimeGameData 7.1.0 `ExcelBinOutput` (no reshape/dust table exists client-side; only `ReliquaryPowerupExcelConfigData` {1,2,5} EXP multipliers and `ReliquaryAffixNormalizedParamExcelConfigData`, a per-stat normalisation constant, not a weight), Tieba/Zhihu (403).
- BWIKI `启圣之尘` pity wording: "每触发2次「高阶重塑」，下一次触发高阶重塑效果时（也就是消耗18个启圣之尘），会改为触发「谕告重塑」" (the third Advanced is replaced by Decreed, at 18 Dust), "进度由全部圣遗物共享" per a Zhihu snippet (progress is shared across all artifacts and slots). Cost 1/1/2/2/2 vs BWIKI listing 羽/花 1, 冠/沙/杯 2 (confirms prior doc).

## Item 1 — shape of the 5-star count per domain run at AR45+: **still unverified** (nothing measured)
What exists:
- **Mean, measured:** GDGT *Drop Rates* sheet (https://docs.google.com/spreadsheets/d/10DF-Wqn-79SxTeSZPAY__RW1uGtpphAx4rG97akYskY, tab gid 749900704 and its copy 1725629394, read as CSV on 2026-10-24): Domain of Blessing AR 45, **n = 14,088 runs, 5-star mean 1.07** (cell computed 1.067664964). Per-domain AR 45 rows: 765 / 1,021 / 1,860 / 2,578 / 2,081 / 3,201 / 1,577 / 645 / 360 runs, means 1.06-1.08. These are **means only**. The sheet carries no per-run distribution, no count of 2-star runs. The sheet's own changelog (tab gid 391738645): created 2022-08-20; "13 Jul 2025 Added WL9 entries for world bosses"; "27 May 2026 Added missing imported spreadsheet - the original owner decided to delete the sheet but luckily I had a backup" (.mcpie). The raw per-run data tabs are not in the published copy.
- **Consistency check (derived):** if the count were 1 + Bernoulli(p), the SE of the sample mean at n = 14,088 is sqrt(p(1-p)/n) ~ 0.0021, so 1.0677 vs 1.065 is within 1.3 SE. The mean cannot discriminate between shapes.
- **Structure hint (derived):** W-DROP's AR45 domain row is 3.55 / 2.485 / 1.065 of 7.1 total = 50% / 35% / 15% of 7.1; the same 50/35/15 split gives the WL7 boss row (2.1/1.47/0.63 of 4.2). At WL8 the boss's 5-star is replaced by a fixed 1 (measured 1.00 over 11,197 runs; per-boss samples all 1.00), which is a deterministic count. For the domain the table is a prediction of the mean (the page says "distribution prediction for the **mean**") and the game's preview shows the same expected-value figures, so the table says nothing about variance.
- **Quote, claims of a maximum of 2:** a Zhihu answer by Pandora Eartha (https://www.zhihu.com/question/506348362/answer/2678619089; the page is login-walled/403 to us, so this is known only from a search-result summary) is said to give "90级圣遗物秘境每次有100%概率掉落一个五星圣遗物，另有7%概率额外掉一个，最多两个" (100% one, a further 7% chance of one extra, at most two). Not independently read; no sample cited.
- **Quote, small personal sample:** NetEase blog by solay, 2020-10-26 (https://www.163.com/dy/article/FPSTKIMH0546N0WI.html): 39 AR45 domain runs, "其中包括30次火本和9次风本" with 2 double-golds, "目前的样本量仅为5%左右（有可能更低）", and "并不确实是否会出现三金或者以上的情况" (does not know whether 3+ occurs). 2/39 = 5.1% (95% CI roughly 0.6%-17%), so it is compatible with 6.5%, and says nothing about 3+.
- **Quote, claims that only appear as a mean:** gamersky (blue菌hehe, 2021-08-19, https://www.gamersky.com/handbook/202108/1416711.shtml): "三种途径每次均必掉一个金圣遗物，小概率掉落两个金圣遗物，掉落数量的期望值为…" followed by an image that reads (viewed): 祝圣秘境 1.065 / 普通boss 1 / 周常boss 1.23. Miyoushe (暖阳, 2026-05/06, post 75218977): "20原粹树脂可以获得1个五星圣遗物…极小概率额外获得1个五星圣遗物".
- **Conflicting retail-blog claims** (low quality, a top-up shop; both in search summaries only): one gives "93.5% chance for 1 item and 6.5% chance for 2 items" (1.065 split as 1 + 0.065), another on the same site "10-15% chance of getting two".
- **Implementation precedent:** `j4rv/genshinartis` `main.go` (pushed 2024-05-10) hardcodes `AverageDropsPerDomainRun = 1.065` and `DomainExtraArtifactChance = 0.065`, and `xelox/impact-simulation` `art-sim.js` uses `artifactsPerDomain = 1.065`. These are assumptions, with no citation in the code; they do not count as evidence.
- **Not reachable:** NGA tid=33220261 ("访客不能直接访问", guest-blocked), Zhihu, Reddit (blocked to scripts), Genshin Data Gathering Discord. The prior doc's NGA reference remains unread.
- **What follows:** for the model, "1 + Bernoulli(0.065)" is the minimum-variance shape consistent with mean and guarantee. Whether 3+ is possible is not known; if it were, the extra mass would sit in the tail and the mean constraint would force P(2) lower than 6.5%. State the model's variance as an assumption.
